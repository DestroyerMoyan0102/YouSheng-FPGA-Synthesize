# 友声 YouSheng
### 基于 FPGA 的实时多音色合成电子乐器

> 一款集实时演奏、多音色合成、可视化交互与辅助演奏于一体的 FPGA 电子乐器系统。

**硬件平台：** Sipeed Tang Mega 60K  
**开发环境：** Gowin EDA  
**设计语言：** Verilog HDL  
**项目类型：** FPGA 实时音频合成与人机交互系统

---

## 1. 项目简介

**友声（YouSheng）** 是一款基于高云 Tang Mega 60K FPGA 开发板设计的实时多音色合成电子乐器。

系统以 FPGA 为核心控制与运算平台，结合电容触摸键盘、旋转编码器、实体控制按键、LCD 显示屏和音频输出模块，实现从演奏输入、音符识别、音频合成到声音输出的完整处理流程。

在基础电子乐器功能之外，本作品还加入了**辅助演奏、节拍器、双声道控制及实时波形可视化**等功能，兼顾演奏体验、交互性与教学辅助价值。

## 2. 核心功能

### 2.1 多维交互控制

- **15 键电容触摸键盘：** 支持音符触发、单音演奏及多键和弦输入。
- **旋转编码器：** 控制演奏音域切换，按下可恢复默认音域。
- **实体按键：** 支持音量增减、音色与颤音切换、声道控制及节拍器切换。
- **长按连续调节：** 音量控制支持连续增减，提高操作便利性。

### 2.2 实时多音色合成

系统通过 FPGA 内部数字逻辑完成音频信号生成与处理。

主要功能包括：

- 钢琴音色与复古电子音色切换
- 波表合成与音频波形生成
- ADSR 包络控制
- 颤音效果调制
- 多音符同时发声与实时混音
- PCM 数字音频处理与输出

音色与颤音采用四状态循环切换：

| 状态 | 音色 | 颤音 |
|---|---|---|
| 1 | 钢琴 | 关闭 |
| 2 | 钢琴 | 开启 |
| 3 | 复古电子音 | 关闭 |
| 4 | 复古电子音 | 开启 |

### 2.3 LCD 实时可视化

系统通过 LCD 显示屏实时反馈演奏状态，主要显示内容包括：

- 当前音色模式（MODE）
- 当前音域（OCTAVE）
- 音频波形（WAVEFORM）
- 音量大小（VOLUME）
- 最近触发的音符（NOTE）
- 虚拟琴键与触摸状态

界面根据演奏输入和控制参数动态更新，实现声音与视觉的同步交互。

### 2.4 辅助演奏模式

作品设计了独立的辅助演奏模式，以降低初学者的演奏门槛。

通过指定触摸按键进入辅助演奏模式后：

1. LCD 界面切换为紫色主题。
2. 屏幕显示与琴键位置对应的音符指引方块。
3. 指引方块随时间向目标琴键移动。
4. 演奏者根据屏幕提示触摸对应琴键。
5. 系统根据输入更新指引状态。

内置示例曲目为《小星星》。

辅助演奏模式与原有音色、音量控制功能相结合，使演奏练习更加直观。

### 2.5 节拍器

系统内置节拍器功能，提供：

- 关闭节拍器
- 节拍模式一
- 节拍模式二

节拍提示采用不同音效区分节拍位置，首拍使用提示音“叮”，后续节拍使用“哒”，帮助演奏者保持节奏。

### 2.6 双声道控制

系统支持左右声道控制，通过实体按键切换声道输出状态，丰富演奏时的听觉表现。

## 3. 系统架构

系统主要由输入交互、控制逻辑、音频合成、显示控制及音频输出五部分组成。

```text
             ┌──────────────────────┐
             │     用户交互输入      │
             │                      │
             │  电容键盘 / 实体按键   │
             │     旋转编码器        │
             └──────────┬───────────┘
                        │
                        ▼
             ┌──────────────────────┐
             │    FPGA 控制逻辑      │
             │                      │
             │ 音符识别 / 音域切换    │
             │ 音色选择 / 状态管理    │
             └──────────┬───────────┘
                        │
            ┌───────────┴───────────┐
            ▼                       ▼
  ┌──────────────────┐   ┌──────────────────┐
  │    音频合成引擎   │   │   LCD 显示系统   │
  │                  │   │                  │
  │ 波形生成 / ADSR   │   │ 参数状态可视化    │
  │ 颤音调制 / 混音   │   │ 波形与琴键显示    │
  └────────┬─────────┘   │ 辅助演奏指引      │
           │             └──────────────────┘
           ▼
  ┌──────────────────┐
  │    音频输出模块   │
  │                  │
  │   数字音频传输    │
  │    DAC 转换      │
  │  耳机 / 扬声器    │
  └──────────────────┘
```

系统采用模块化 Verilog HDL 设计，各功能模块通过顶层逻辑连接，实现演奏输入、音频生成与可视化显示的协同工作。

## 6. 开发环境与工程使用

### 6.1 开发环境

- FPGA 开发板：Sipeed Tang Mega 60K
- FPGA 芯片：GW5AT-LV60PG484AC1/I0
- 开发工具：Gowin EDA
- 硬件描述语言：Verilog HDL

### 6.2 工程构建

本仓库提供 Verilog 源代码及约束文件，未包含完整的 Gowin IDE 工程配置文件。

可参考以下步骤建立工程：

1. 安装支持目标 FPGA 器件的 Gowin EDA。
2. 创建新的 FPGA 工程。
3. 选择与 Tang Mega 60K 开发板匹配的器件及封装。
4. 将仓库中的 Verilog 文件添加至工程。
5. 设置 `top.v` 对应的顶层设计模块。
6. 导入 `top.cst` 引脚约束文件。
7. 导入 `top.sdc` 时序约束文件。
8. 检查时钟、PLL、外设接口和相关 IP 配置。
9. 执行综合、布局布线及比特流生成。
10. 将生成的配置文件下载至 FPGA 开发板进行验证。

**注意：** 实际运行需要匹配的外设硬件、引脚连接及工程配置。仅导入源代码并不保证在不同硬件环境下直接运行。

## 7. 项目特色

**实时多音色合成**

利用 FPGA 并行处理能力，实现多音符生成、音色处理与数字音频混合。

**多维演奏交互**

结合电容触摸、实体按键及旋转编码器，实现音符输入与演奏参数控制。

**可视化演奏反馈**

通过 LCD 实时显示音色、音量、波形和琴键状态，提升交互体验。

**辅助演奏功能**

采用音游式视觉引导，将音符提示与琴键位置关联，辅助初学者进行演奏练习。

**模块化硬件设计**

使用 Verilog HDL 对音频、交互及显示功能进行模块化实现，便于后续扩展和优化。
